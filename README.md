# 🏗️ Build_manage — Construction Management System

A web-based construction management application designed to simplify the management of construction materials, trucks, and projects through a centralized dashboard.

## 📌 Overview

Build_manage is a Python Flask-based web application that helps organize essential construction management operations in one place. It provides a simple interface for managing material inventory, tracking truck details, and maintaining project information.

The project demonstrates practical implementation of backend development, database management, and web application fundamentals.

## ✨ Features
 📊 Dashboard: View key construction management information in one place.
🧱 Material Management: Add and manage construction materials, quantities, and prices.
 🚚 Truck Management: Maintain truck details and capacity information.
🏢 Project Management: Store and organize construction project details.
 💰 Inventory Valuation: Calculate total material inventory value using quantity and price.
🗄️ Database Integration: Store application data using SQLite and Flask-SQLAlchemy.
 🌐 Web Interface: Use HTML templates and static assets to build the application interface.

⚙️ Installation & Setup

Follow these steps to run the project locally.

## 1. Clone the repository
git clone https://github.com/Anshii28/Build_manage.git

## 2. Navigate to the project directory
cd Build_manage

## 3. Create a virtual environment
python -m venv venv


## Activate it:

## Windows

venv\Scripts\activate


## macOS / Linux

source venv/bin/activate

## 4. Install dependencies
pip install -r requirements.txt

## 5. Run the application
python app.py


Open your browser and visit:

http://127.0.0.1:5000/


 Note: Make sure Python is installed and the required dependencies are available before starting the application.
